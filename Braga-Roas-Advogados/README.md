# Como alterar os textos

Todo o conteúdo está localizado em:

```
index.html
```

Altere normalmente:

- títulos
- subtítulos
- descrições
- telefones
- endereço
- WhatsApp
- e-mail

---

# Como alterar as imagens

Substitua os arquivos da pasta

```
images/
```

pelos arquivos definitivos.

Mantenha os mesmos nomes ou atualize o caminho no HTML.

É recomendado utilizar imagens em:

- WebP
- AVIF

---

# Logotipo

Substitua:

```
images/logo.png

images/logo-footer.png
```

pelos arquivos oficiais.

---

# WhatsApp

No arquivo:

```
index.html
```

Localize:

```
https://wa.me/5531999999999
```

e substitua pelo número oficial.

Exemplo:

```
https://wa.me/55319987654321
```

---

# Google Maps

Localize o iframe do Google Maps.

Substitua o link Embed pelo endereço oficial do escritório.
